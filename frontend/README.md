# OPERATION PRAHAAR AI — COMMAND CENTER FRONTEND
### Professional Indian Defence-Inspired Command Dashboard

## Technology Stack:
- **Framework:** React 18+ with TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS (Custom Army-Inspired Olive `#1B2E1E`, Charcoal `#0F1412`, Radar Green `#4ADE80`, Muted Gold/Saffron `#F59E0B` Accents)
- **Icons:** Lucide React
- **Visual Feel:** High-contrast tactical command centre, dark mode by default, crisp typography, clean data cards.

## Planned Views:
1. **Overview Dashboard:** High-level operational readiness, live incident feeds, active cameras, edge node health.
2. **Camera Management:** CCTV stream registry, zone polygon configurations, connection status.
3. **Live / Sample Video Monitoring:** Visual player with real-time bounding overlays and crowd density heat gauge.
4. **Crowd Analytics:** Congestion graphs, flow estimation, peak time indicators.
5. **Safety Events:** Stream of edge-detected spatial events.
6. **Incident Management:** Grouped situational assessments with priority indicators.
7. **Security Intelligence:** Advisory correlations and threat indicators.
8. **Alert Center:** Actionable alerts with severity and confidence scores.
9. **Human Verification Console:** Dedicated operator interface to Verify, Dismiss, or Escalate.
10. **Audit Logs:** Immutable chronological ledger of all operator reviews and system actions.
11. **Edge Device Management:** Edge node CPU, memory, uptime, and communication status.
12. **System Settings:** Retention policies, threshold adjustments, and responsible AI safeguards.

*Note: Frontend structure and setup will be executed in Phase 3.*
